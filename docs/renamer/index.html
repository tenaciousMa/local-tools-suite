核心功能

批量操作，一次配置

01 / TEMPLATE

自由命名模板

组合日期、时间、序号、原文件名和说明文字，实时查看结果。

02 / PREVIEW

表格预览

原名、修改时间、目标文件名和状态集中显示，确认后再执行。

03 / OUTPUT

改源文件或导出 ZIP

可以直接修改原文件名，也可以只生成 ZIP 副本，避免影响源文件。

04 / IMPORT

文件、文件夹与拖拽导入

支持一次选择多文件，也能递归读取文件夹或直接拖入窗口。

05 / CONFLICT

同名冲突处理

目标已存在时自动追加序号，避免覆盖原有文件。

06 / LOCAL

完全本地处理

不上传文件，不需要账号，不依赖 Node、Python 或浏览器。

命名变量

文件名按规则生成

模板中可以直接输入文字，也可以插入结构变量。

  • {date} 完整日期与时间
  • {YYYY}年{MM}月{DD}日 中文日期
  • {HH}时{mm}分 时间
  • {num} 自动序号
  • {name} 原文件名
  • 自定义文字、前缀、后缀与分隔符
